# 大众安徽 ID. 律动线框规则

## 适用范围与来源

本规则仅适用于“大众标徽 + 律动线框”组合，不等同于完整的 VW 标志规范。执行时使用绑定的原始规范 PDF：

`assets/brand-guidelines/volkswagen-anhui/05-律动线框_VW_ID_Guideline_Moving frame_CN.pdf`

- 文件版本：`VW_ID._Guideline_Moving frame_CN`
- 文件分类：Internal
- 文件日期：2024-05-13
- 原文说明：手册画面仅作设计示意，不得与真实传播车型或图片直接对应。

使用律动线框时，必须同时读取 `volkswagen-anhui-colors.md` 和 `volkswagen-anhui-logo-wordmark.md`。普通 VW 标志的四周保护区为 `0.5D`；官方律动线框作为例外组合，标志外缘到线条起点的间距为 `0.25D`。

## 核心定义

- 律动线框由简约线条与大众标徽构成一个整体。
- 标徽可沿安全范围内的线条灵活定位，但标徽与线条的相对几何结构严格固定。
- 律动线框应放在 ID. 版式色板的对向。

## 颜色

- 律动线框仅限使用“午夜黄”或“午夜灰”。
- 禁止在 ID. 传播中使用大众深蓝色律动线框。
- 根据背景选择黄色或灰色版本，必须保证高对比度、足够安全空间和清晰可读性。
- 使用 `volkswagen-anhui-colors.md` 中的精确标准色值，不从 PDF 截图吸色。

## 标徽与线条结构

将大众圆形标徽直径定义为 `X`：

- 标徽中心必须与律动线框线条中心水平或垂直对齐。
- 线条固定放在标徽两侧，或在垂直组合中放在标徽上下。
- 标徽外缘与每段线条起点的间距必须等于 `0.25X`，禁止增大。
- 标徽任意一侧的可见线条长度不得小于 `0.65X`。
- 不得改变标徽与线条的相对位置、对齐关系或间距。

## 线宽公式

### 数字媒体

- 线宽（px）=`X / 32`，小数四舍五入。
- 最小线宽为 `1px`。
- 手册示例：`X = 30px` 时线宽 `1px`；`X = 70px` 时线宽 `2px`。

### 印刷媒体

- 将以 mm 为单位的标徽直径乘以 `0.075`，得到以 pt 为单位的线宽。
- 最小线宽为 `1pt`。
- 手册示例：`X = 10mm` 时线宽 `1pt`；`X = 76mm` 时线宽 `5.7pt`。

## 版式方向与极限定位

- 在一部分横版或方版中，律动线框遵循色板方向横向放置；其垂直方向的极限定位为画板高度的 50%。
- 在大部分横版中，律动线框遵循色板方向竖向放置；其水平方向的极限定位为画板宽度的 50%。
- 在竖版中，律动线框遵循色板方向横向放置；其垂直方向的极限定位为画板高度的 50%。
- 手册示意图中的 `0.5X` 与 `0.45X` 安全边界与具体版式有关。不要将任一数值当作所有版式的通用页边距；使用官方模板或对照原 PDF 的对应布局。
- 横版中的线条应在对应方向上撑满版式，不得随意缩成短装饰线。

## 3D 应用

- 律动线框可跨越四个面并在各面之间整合。
- 大众标徽只能出现一次，建议放在 3D 物料最显眼的一面。

## 禁用项

- 不得使用大众深蓝色律动线框。
- 不得使用明显过粗的线条；按线宽公式计算。
- 标徽与线条间距不得大于 `0.25X`，标准执行值为 `0.25X`。
- 任一需要可见的线段不得少于 `0.65X`；特别检查左侧线段。
- 横版中不得让线框未撑满应有方向。
- 律动线框不得裁切、穿过或遮挡车辆和人物。

## 生产方式

- 使用官方 VW 标志矢量资产及律动线框规范图作为 ImageGen 身份参考；生成结果必须保持官方构造、比例、线距、线宽和颜色，不允许模型自由重绘或变形。
- 将标徽与线条作为一个可编辑的绑定组件，用公式计算间距、最小线长和线宽。
- 在最终像素尺寸下计算数字媒体线宽，不在缩放后依赖非整数描边。
- 在生成或重新构图背景时，预留连续线条路径，确保不穿过车辆、人物或关键文字。

## 质检清单

- [ ] 使用午夜黄或午夜灰，没有使用大众深蓝。
- [ ] 背景对比度和空间允许整个组合清晰识别。
- [ ] 标徽中心与线条中心对齐。
- [ ] 标徽边缘到线条起点的间距为 `0.25X`。
- [ ] 各需要可见的线段长度至少为 `0.65X`。
- [ ] 数字端线宽为四舍五入后的 `X/32 px` 且不小于 `1px`，或印刷端符合 `0.075X pt` 且不小于 `1pt`。
- [ ] 律动线框未裁切或穿过车辆、人物和关键内容。
- [ ] 横版线框撑满规定方向，竖版或方版的极限定位正确。
- [ ] 3D 应用只有一个大众标徽。
