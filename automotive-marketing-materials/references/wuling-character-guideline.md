# 五菱“小五、小菱”IP 角色规范

## 来源与适用范围

仅在使用五菱官方 IP 角色小五（英文名 `Wula`）、小菱（英文名 `Ling`）或相关角色纹样时读取本文件。正式来源：

`assets/brand-guidelines/wuling/Wuling_Characters_Guideline_CH0326.ai`

- 文件标题：WULING CHARACTER GUIDELINE
- 版本：2021.03
- 文件格式：带 53 页 PDF 兼容内容的 Adobe Illustrator 文件
- 内容：角色关系、比例、2D/3D 转面、颜色、表情、动作、物件、纹样、贴纸与禁用规则

该文件是受版权保护的角色规范与矢量生产资产。不得擅自修改、公开、转授权或把 AI 文件作为普通交付附件分发；特殊使用或规范未覆盖的动作应咨询设计师或品牌方。

## 角色体系

- 中文名称必须固定为“小五”和“小菱”：`Wula` 是小五的英文名，`Ling` 是小菱的英文名。
- 所有面向中文用户的画面文字、标题、说明、文件清单和交付备注统一写“小五”“小菱”。仅在英文画面、双语首次释义、原始文件名或资产检索中使用 `Wula`、`Ling`。
- 不把 `Wula` 直译或另译成其他中文名称，也不把 `Ling` 与 Ling OS、LING Club、LING HOUSE 等品牌名称混淆。
- 主角色小五，辅助角色小菱。
- 小菱高度为 `1 Lingmeter` 时，小五高度为 `3.7 Lingmeter`；必须保持 `3.7:1` 的官方比例关系。
- 小五有 Basic Red、Basic Mint 和 Wula Sunglass 等官方样式；2D 与 3D、红色与薄荷色版本不得在同一组合中随意混用。
- 使用规范内已有的官方转面、表情、动作与互动姿势；新动作或新角度需要品牌批准，不让图像模型自由重画角色结构。

## 颜色

### 小五 Wula - Basic Red

- 主色 `#FE636A` / CMYK `0,76,48,0` / Pantone `2345 C`
- 点缀灰 `#D9E3F4` / CMYK `13,6,0,0` / Pantone `656 C`
- 白 `#FFFFFF` / Pantone White
- 辅色：`#FFA09A`、`#FFDFDE`、`#FFE657`、`#000000`
- 推荐背景：`#76DBFF`、`#77D7D6`、`#FFF0AE`、`#879DB3`

### 小五 Wula - Basic Mint

- 主色 `#94E5D1` / CMYK `38,0,24,0` / Pantone `332 C`
- 点缀灰与白同上；辅色同 Basic Red。
- 推荐背景：`#FFB8B9`、`#C9F7D1`、`#FFF0AE`、`#879DB3`

### 小菱 Ling

- Red 版主色 `#FE636A`；Mint 版主色 `#94E5D1`。
- 点缀色 `#0EE1C0` / CMYK `62,0,38,0` / Pantone `2239 C`。
- 辅色：`#D9E3F4`、`#000000`、`#FFFFFF`。

所有角色颜色按官方值执行，不从截图吸色。角色配色是 IP 专项色，不取代五菱品牌主色，也不用于重绘五菱 Logo。

## 使用规则

- 使用官方 2D/3D 角色资产，不从 PDF 截图抠取，不用 AI 生成近似角色。
- 角色头部与身体比例不得改变；小五和小菱的相对尺寸不得改变。
- 不修改角色线条粗细，不拉伸、压扁、旋转局部或替换五官。
- 不混用不同渲染风格、不同版本或不兼容的角色搭配。
- 使用指定或推荐背景色，避免同色系背景削弱角色轮廓；必要时选择官方允许的更高对比背景。
- Pattern A、Pattern B 与 Sticker 只使用官方构图或从原 AI 文件调用，不随意重排成新纹样。
- 规范要求明示版权标记或合作形式；具体文字和落位应由用户或品牌方提供，缺失时先询问。
- 若本次传播不需要 IP 角色，不加载或装饰性加入小五 / 小菱。
