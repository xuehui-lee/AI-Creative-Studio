# 五菱银标视觉识别专项规则

## 来源与优先级

所有五菱银标视觉必须读取本文件。正式来源：

`assets/brand-guidelines/wuling/A五菱银标视觉识别手册.pdf`

- 文件标题：五菱银标品牌视觉识别手册
- PDF 标题：A五菱银标视觉识别手册-基础部分转曲
- 制作日期：2024-09-25
- 全册：111 个 PDF 页面

本手册是银标系的专项补充规范。Logo 相关事项以 `wuling-brand-visual-guideline.md` 对应的《五菱品牌视觉识别规范 2.0 版》为最高优先级依据；本手册只补充 2.0 版未覆盖的银标锁定关系、媒介应用、影像气质和辅助视觉等事项。如 Logo 选择、结构、颜色、背景版本、位置、尺寸、安全空间、组合关系或禁止项与 2.0 版冲突，一律服从 2.0 版。

## 品牌精神与影像方向

- 品牌精神关键词：关爱、进取、可靠。
- 人物：以中国人和中青年为主，充满活力、有品质感，动作与生活关系真实。
- 场景：画面干净简约、场景大气开阔、有品质感；可使用现代建筑、开阔道路、城市天际线和自然空间。
- 车辆和材质需清晰、精工、有高级感，但不做浮夸豪华叙事。

## 银标及锁定关系

- 使用官方银标、中文“五菱汽车”标准字和英文 `WULING` 标准字资产，不从手册抠取或用字体重建。
- 常用对外宣传优先采用“银标 + 英文标准字”的官方组合；具体媒介选择必须参照原手册第 24 页的标志使用范围矩阵。
- 画面过小、不利于标识语识别时，不放标识语。
- 单独银标、中文横排、英文横排、中文上下、英文上下及含标识语版本均为不同官方组合，不得自行拆分或重新排距。
- 中文横排与英文横排组合的保护区为四周至少 `0.5a`，其中 `a` 为银标宽度；印刷最小宽度分别为中文 `30 mm`、英文 `25 mm`。
- 中文上下组合：银标高 `0.52a`，标志与中文间距 `0.05a`，中文字高 `0.19a`、宽 `0.93a`。
- 银标上下组合的外部安全空间：四周至少 `0.25a`；印刷最小宽度 `30 mm`。
- 深底含标识语锁定关系使用 `0.3a` 外部安全空间。其他含标识语的精确尺寸和间距必须直接回看原 PDF 第 22-23 页。
- 当银标置于浅色背景导致识别不清时，先按 2.0 版的 Logo 背景明度规则选择菱空蓝或白色飞翔标及对应官方组合。只有 2.0 版未覆盖且银标专项手册明确要求时，才使用官方深底银标版本；不得自创底板、改黑、描边或加阴影。

## 银标色彩

### 标准银色

| 名称 | Pantone | CMYK | RGB | HEX |
|---|---|---|---|---|
| 全球银 | `Pantone 538 C` | `27,16,11,0` | `196,207,218` | `#C4CFDA` |

全球银表达“可靠 / 品质”。数字显示使用 RGB/HEX，常规印刷使用 CMYK，品牌精确复制优先 Pantone。

### 辅助色

| Pantone | CMYK |
|---|---|
| `7546 C` | `87,80,70,54` |
| `1505 C` | `0,71,100,0` |
| `7509 C` | `21,41,66,0` |
| `283 C` | `47,17,2,0` |
| `2925 C` | `78,29,3,0` |
| `1235 C` | `0,38,86,0` |

手册没有为这些辅助色提供 RGB/HEX。不得从 PDF 截图吸色或自行换算后宣称为官方数字色；数字媒体需要使用时，向品牌方索取批准的 RGB/HEX，或明确标注为待确认。

### 背景应用

- 银标始终与背景保持足够对比。
- 背景颜色应属于银标辅助色体系；若为其他浅色背景且标志不清晰，使用官方深底银标。
- 不使用与银标明度接近的背景，不在深色渐变中反白银标，不使用构图或颜色复杂、干扰识别的背景。
- 规范提供了从浅到深的明度示例；以视觉清晰度和官方深底版本为判断依据，不自行给银标加效果。

## 字体

### 品牌传播

- 中文：方正兰亭黑系列。
  - 主标题：方正兰亭大黑简体。
  - 副标题、正文标题：方正兰亭中黑简体。
  - 正文：方正兰亭纤黑简体。
- 英文：Avenir。
  - 主标题：Avenir Black。
  - 副标题、正文标题：Avenir Medium。
  - 正文：Avenir Light。

### 办公环境

- 中文：黑体。
- 英文：Arial Bold / Arial Regular。

当前 Skill 未绑定这些字体文件。正式交付前确认授权字体可用；缺失时向用户索取字体包或批准的回退方案，不得静默替换。

## 辅助视觉与图标

- 银标辅助图形、纹样和排版弧线使用手册提供的官方构造或资产，不从缩略图描摹。
- 交互图标必须保持统一网格、安全距离、视觉重量和圆角语言；彩色图标始终与周围区域保持明显对比。
- 需要 APP、社交、网页、户外、车辆侧面或办公模板时，回看原手册对应章节，不把单一版式跨媒介拉伸。

## 质检清单

- [ ] 已确认这是银标系任务，并同时读取五菱总规范。
- [ ] 使用正确的银标官方组合，没有自行拆分、重排或重打标准字。
- [ ] 全球银使用 `#C4CFDA / RGB 196,207,218`；辅助色未擅自转换成官方数字色。
- [ ] 安全空间和最小尺寸符合所选锁定版本。
- [ ] 浅底识别不足时使用官方深底版本，没有描边、阴影或任意反白。
- [ ] 人物、场景、车辆和整体质感符合“关爱、进取、可靠”。
- [ ] 字体与媒介匹配，缺少授权字体时没有静默替换。
