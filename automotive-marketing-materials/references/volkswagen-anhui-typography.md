# 大众安徽品牌字体规则

## 适用范围与资产

所有包含文字的大众安徽视觉必须读取本文件，并优先使用 Skill 内绑定的字体文件：

`assets/brand-guidelines/volkswagen-anhui/fonts/`

字体包未附独立授权文件。仅将其作为用户提供的受控品牌生产资产使用；不得把字体文件作为交付附件对外分发，不得上传公共字体服务，也不得自行转换为 WOFF/WOFF2 或嵌入公开网页。若项目需要网页嵌入、转授权或外部供应商使用，先向品牌方确认授权范围。

## 字体清单与字重映射

### 中文：汉仪旗黑

| 文件 | 内部字体名 | 用途 |
|---|---|---|
| `中文/HYQiHei-40S.ttf` | 汉仪旗黑 40S / UltraLight | 辅助信息、说明文字、正文和较轻层级 |
| `中文/汉仪旗黑-60S.ttf` | 汉仪旗黑 60S / Regular | 标题、价格、CTA 和需要强调的中文信息 |

包内只有 40S 与 60S。不得通过软件伪造粗体、伪造斜体或描边来制造不存在的中文样式。需要更重字重时，优先通过字号、留白、色彩和层级强化；若仍不足，向品牌方索取批准的字体文件。

### 英文与数字：VW Head

| 文件 | 内部样式 | 建议用途 |
|---|---|---|
| `英文/VWHead-Light.otf` | Light | 辅助英文与轻量信息 |
| `英文/VWHead-Regular.otf` | Regular | 正文、常规英文与数字 |
| `英文/VWHead-RegularItalic.otf` | Regular Italic | 经版式意图确认的英文强调 |
| `英文/VWHead-Bold.otf` | Bold | 标题、价格数字、CTA |
| `英文/VWHead-BoldItalic.otf` | Bold Italic | 经版式意图确认的强强调英文 |
| `英文/VWHead-ExtraBold.otf` | ExtraBold | 极少量关键英文或数字 |

仅使用包内真实样式，不由排版软件合成粗体或斜体。

## 排版执行

- 中文字符使用汉仪旗黑；拉丁字母、阿拉伯数字和西文标点优先使用 VW Head，并按语种分段设置字体。
- 从零生成完整海报时，将车型官方名称、价格数字、单位、日期、CTA 与免责声明按原文和换行交给 ImageGen 同次生成，并提供绑定字体作为字体风格参考；逐字核对，不得接受错字、漏字、伪字或数字漂移。已有模板排版任务仍使用可编辑文字层。
- 字重选择服从信息层级，不能为了“更有冲击力”把所有信息设为 Bold 或 ExtraBold。
- Italic 仅用于明确需要斜体的拉丁内容，不倾斜中文，也不机械倾斜 Logo 或 ID. 文字标识。
- 不拉伸、压扁、扭曲字体，不用人工描边替代缺失字重。
- 字体颜色同时遵守 `volkswagen-anhui-colors.md`；VW 标志和 ID. 文字标识必须以官方图形资产作为 ImageGen 身份参考，不用 VW Head 或汉仪旗黑重新设计其结构。
- 最终定稿需检查缺字、替换字体、错行、标点挤压、数字基线和中英文混排间距。
- 输出可编辑源文件时保留文本层。对方无品牌字体环境且授权允许时，可额外提供文字转轮廓版本；字体文件本身不随成品打包。

## 缺字与回退

1. 先确认字符是否为错别字、异体字或未经批准的特殊符号。
2. 在已提供的汉仪旗黑 40S/60S 与 VW Head 字体中检查可用字形。
3. 若缺字，停止最终导出并向用户索取品牌批准的回退字体或转曲字形；不得静默回退到系统字体。
4. 若只是制作预览，可使用清晰标记的临时回退字体，但不得将其作为正式交付。

## 质检清单

- [ ] 中文使用汉仪旗黑 40S 或 60S，英文与数字按需要使用 VW Head。
- [ ] 没有伪粗体、伪斜体、拉伸、压扁或描边仿字重。
- [ ] Logo 与 ID. 文字标识使用官方文件作为 ImageGen 身份参考，生成结果没有被普通字体替代或重构。
- [ ] 全部定稿文字逐字正确，没有缺字或系统字体静默替换。
- [ ] 中英文、数字、单位、标点的基线与间距自然。
- [ ] 最终输出已在实际像素尺寸检查小字可读性。
- [ ] 字体文件没有被打包进对外交付物，授权不明确时没有进行网页嵌入或格式转换。
