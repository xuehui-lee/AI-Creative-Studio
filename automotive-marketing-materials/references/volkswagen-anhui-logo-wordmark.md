# 大众安徽 VW 标徽与 ID. 文字标识规则

## 适用范围与来源

本规则分别管理两个不同对象：

1. 圆形 VW 标徽（VW logo）。
2. `ID.` 文字标识（ID. logo / wordmark）。

不得混用两者的保护区、最小尺寸或颜色规则。执行时使用绑定的原始规范 PDF：

`assets/brand-guidelines/volkswagen-anhui/01_VW_ID_Guideline_logo&wordmark_DSSO.pdf`

- 文件版本：`VW_ID_Guideline_Logo&Wordmark_EN`
- 文件分类：Internal
- 文件日期：2023-05-12
- 原文说明：手册仅作设计示意，不得将其车型名或图片当作真实营销素材依据。

使用本规范时必须同时读取 `volkswagen-anhui-colors.md`，以颜色专项规范作为标准色值的主来源。

## VW 圆形标徽

### 资产与外观

- 使用正式标志文件作为 ImageGen 身份参考，不用普通字体、压缩截图或手工轮廓替代；禁止模型脱离官方参考自由设计近似标志。
- 保持简洁平面效果：不加渐变、图片填充、阴影、立体、描边或其他特效。
- 不拉伸、压缩、倾斜、旋转、改变线宽或内部留白。
- 背景保持安静，不在圆环背后放置线宽或颜色相近的图形、主导结构或复杂纹理。
- 不把 VW 标志与任意其他元素改造成新组合标志。律动线框仅按官方专属规范作为例外组合。

### 合法颜色组合

仅使用手册指定的三种主色组合：

- 午夜黄标徽 / Zero 背景。
- 午夜黄标徽 / 午夜灰背景。
- Zero 标徽 / 午夜黄背景。

午夜黄标徽是设计首选。所有标准色值使用 `volkswagen-anhui-colors.md`，不从 PDF 截图吸色。

### 保护区

将圆形 VW 标徽直径定义为 `D`：

- 标徽上、下、左、右每一侧的常规保护区均为 `0.5D`。
- 任何文字或设计元素不得进入保护区。
- 数字与印刷官方标志文件已包含相应边界时，优先保留文件原有边界。
- 律动线框是受控例外：标徽与线条间距使用律动线框规范的 `0.25D`，其他元素仍遵守 `0.5D` 常规保护区。

### 常规版与小尺寸版

| 媒体 | 尺寸 | 必须使用的版本 |
|---|---:|---|
| 数字 | `>= 57px` 直径 | 常规版 |
| 数字 | `32-56px` 直径 | 小尺寸版 |
| 印刷 | `>= 10mm` 直径 | 常规版 |
| 印刷 | `6-9mm` 直径 | 小尺寸版 |

- 小尺寸版拥有更粗的外环、调整过的线宽与内部空间，不得通过缩小常规版代替。
- 手册没有授权低于 `32px` 或 `6mm` 的使用；尺寸不足时改版或请求品牌确认。

### 禁用

- 禁止在标志内填入图片。
- 禁止渐变。
- 禁止使用手册外颜色。
- 不得将车型、人物、文字或复杂图形放入保护区或圆环背后。

## ID. 文字标识

### 资产与用途

- ID. 标识基于 VW Product 字体，仅用于 ID. 相关应用。
- 必须使用官方提供的 ID. 标识图稿，不要通过输入文字自行重建。
- 午夜黄为所有应用的首选版本。
- Zero 版仅用于因生产限制无法使用彩色版的情况，例如压印、贴花或单色输出。

### 精确颜色

**午夜黄**

- Pantone `7403C`
- sRGB `238, 212, 132`
- HEX `#EED484`
- LAB `86, 3, 43`

**Zero**

- Pantone `20-0194 TPM`
- sRGB `13, 23, 26`
- HEX `#0D171A`

### 背景与对比

- ID. 标识仅使用午夜黄或 Zero，根据背景和图片内容选择可读版本。
- 图片背景必须保证足够留白、对比度和清晰度。
- 禁止在午夜灰背景上使用 Zero 版 ID. 标识。
- 不得使用 VW 天空蓝、VW 深蓝或渐变版 ID. 标识。
- 不得使用低对比的图片区域，不得覆盖车辆。

### 保护区与最小尺寸

将 ID. 标识高度定义为 `d`：

- 标识上、下、左、右每一侧的保护区均为 `0.25d`。
- Web 数字媒体高度不得小于 `12px`。
- 移动端高度不得小于 `20px`。
- 印刷媒体高度不得小于 `3mm`。

## 质检清单

### VW 圆形标徽

- [ ] 使用正式常规版或小尺寸版资产，且版本与输出尺寸匹配。
- [ ] 仅使用三种合法主色组合，没有渐变、图片填充和外来色。
- [ ] 普通场景四周保护区均为 `0.5D`。
- [ ] 背景安静、对比充足，无近似线宽、近似色或主导结构干扰标志。
- [ ] 标志未变形、未加效果、未与非官方元素拼成新标志。
- [ ] 如使用律动线框，另外通过律动线框全部检查项。

### ID. 文字标识

- [ ] 使用官方图稿，仅用于 ID. 应用。
- [ ] 使用午夜黄首选版，或有明确生产原因时使用 Zero 版。
- [ ] 颜色值与官方数值一致，无天空蓝、大众深蓝和渐变。
- [ ] 四周保护区均为 `0.25d`。
- [ ] 最小高度符合 Web `12px`、移动端 `20px` 或印刷 `3mm`。
- [ ] 标识没有覆盖车辆，背景对比充足。
