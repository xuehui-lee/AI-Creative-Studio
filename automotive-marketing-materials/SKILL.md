# Automotive Marketing Materials

Produce routine automotive campaign images from approved vehicle, product, brand, and copy assets. Focus on image generation and image processing; do not invent or rewrite campaign copy.

## Core workflow

1. Classify the request as **edit**, **generate**, **compose**, **adapt**, or a combination.
2. Inspect every supplied image before editing. Record pixel size, aspect ratio, transparency, visible defects, asset role, and likely crop constraints.
3. Run the guided intake before research or production. Ask only the earliest missing blocking input, wait for the user's answer, then ask the next missing blocking input. Do not present a full checklist of all missing fields unless the user explicitly asks for the whole list or says they want to provide everything at once.
   - Intake order: brand/task type if unclear → publishing platform → platform placement → exact vehicle model or explicit no-vehicle confirmation → final displayed copy → Wuling Logo option A/B when applicable → Wuling preset/custom visual style when applicable → optional production preferences such as color mood, scene, deadline, and editable source format.
   - A single question may include closely dependent subfields for the same decision, such as “车型、年款/配置、车色” or “平台里的具体版位”. It must not bundle unrelated decisions such as platform, copy, vehicle, Wuling style, and Logo into one request.
   - If the user answers more than one future field voluntarily, record it and skip those later questions. Continue asking only the next unresolved blocker.
   - For a sparse request like “做一张五菱宣传海报”, first ask the platform, not the full intake list.
4. Confirm the vehicle decision before research or production. If the brief does not name an exact model, ask which model, year/generation, trim when relevant, and desired exterior color should appear. If the user intends a brand-only, product-only, or no-vehicle visual, require explicit confirmation that no vehicle is to be shown. Do not infer a model from the brand, campaign theme, reference image, previous task, or available asset library.
5. If a brand or vehicle is named, browse the official brand website before production. Resolve the exact model, year or generation, trim when relevant, exterior color, official vehicle imagery, official logo, and displayed price terminology. Save direct source URLs and access dates.
   - For Volkswagen Anhui and Wuling, also resolve the expected front/rear display-plate or license-plate area and every visible model/trim badge from official images. Record whether each plate is present, what approved text it carries, and the exact spelling, capitalization, position, material, and lockup of body nameplates. Do not invent a real registration number.
   - When an internal brand guideline is bundled for the named brand, treat that guideline as the primary source for Logo construction, placement, color, and spacing. For Wuling, first obtain the user's A/B Logo choice; otherwise 《五菱品牌视觉识别规范 2.0 版》 has priority over the other bundled manuals. Use web research only to obtain current assets and information not defined by the guideline.
   - Treat bundled historical examples as visual evidence, not as normative brand specifications. When an example conflicts with a formal guideline, follow the formal guideline.
6. Confirm the minimum production inputs: publishing platforms, placement within each platform, final displayed copy, confirmed vehicle model or explicit no-vehicle instruction, visual reference or style direction, deadline, and desired editable source format. If the platform, placement, final displayed copy, or vehicle decision is missing, ask only the next missing item in the guided intake order and stop before image production. Do not combine unrelated missing-input questions into one intake unless the user explicitly requests a full intake form.
   - For Volkswagen Anhui/DSSO, an explicit user style wins. Otherwise use the content-type routing in `volkswagen-anhui-dsso-poster-style-library.md`: product proof → 暮金产品纪实, Q&A/knowledge → 先锋问答杂志, offer/price → 金标权益清单, problem/feature guidance → 功能痛点导视, recruitment/experience → 户外体验招募. Ask for a choice only when the content does not establish a dominant route or when mixing directions would materially change a flagship visual.
   - For Volkswagen Anhui/DSSO, unless the user or a mandatory official template specifies another Logo treatment, use the default top-right midnight-yellow VW roundel and full-width horizontal moving frame from `volkswagen-anhui-moving-frame.md`. Do not ask about the Logo when no special requirement is stated.
   - For Wuling, determine the applicable brand or vehicle-series system from the official vehicle source for palette and image style. If the user has not selected a Logo system, ask: “请选择本次五菱素材的 Logo 形式：A 左上横排口号组合标（飞翔标＋WULING＋‘人民的品质出行’），还是 B 顶部居中上下组合标（飞翔标在上、WULING 在下，不含口号）？” Stop before ImageGen until A or B is confirmed; do not choose on the user's behalf. A required official co-brand or placement rule may still override the choice after explaining the conflict.
   - For Wuling, if no complete visual style is specified, present the eight named options from `wuling-poster-style-library.md` and ask the user to choose one or provide a custom style. Scene words, seasons, or colors alone do not satisfy this requirement. Stop before ImageGen until the style is confirmed; do not choose a default on the user's behalf.
7. Resolve dimensions separately for every platform placement. Use the user-approved Xiaohongshu, Weibo, and Douyin presets in `platform-output-routing.md` when the requested placement matches exactly. A current user-supplied template or backend screenshot overrides a preset. For placements without a preset, verify the platform's current official publishing specification; if an exact size cannot be verified, ask the user rather than silently choosing one.
8. Separate required assets into **available**, **officially retrievable**, and **blocking**. Never replace an exact vehicle, product, logo, QR code, legal line, or required copy with an invented substitute.
9. Choose a workflow from references/image-workflows.md.
10. For a newly generated complete visual containing a specified vehicle, give ImageGen the official vehicle images and official Logo asset as identity references, then generate the vehicle, environment, Logo, locked copy, verified price when required, CTA, and disclaimer together in one integrated final render. Let the model choose or adapt the vehicle angle, camera height, perspective, pose, lighting, reflections, contact shadow, environmental occlusion, information hierarchy, and typography placement to fit the scene. Do not generate an empty background and then paste an official vehicle cutout, Logo, or text onto it as the default production method.
   - Official vehicle images are identity references, not foreground layers to be pasted into the generated background.
   - The official Logo is a strict identity reference. Require ImageGen to reproduce its construction, proportions, color, clear space, orientation, and lockup without redesigning it.
   - For DSSO, pass the official VW roundel together with the bundled placement reference and the moving-frame specification. Preserve the top-right anchor, proportional diameter, `0.25D` gaps, calculated line width, full-width horizontal line, midnight-yellow color, and `0.5D` protection from all non-line content. The bottom `ID. 与众` area visible in the placement example is not part of this default Logo component.
   - For a Wuling visual, use only the confirmed Logo option. For **A**, pass `wuling-default-white-logo-lockup.png` and follow the left/top/width placement rules in `wuling-brand-visual-guideline.md`. For **B**, use `wuling-logo-option-b-user-form-reference.png` together with `examples/wuling-logo-option-b-placement-reference-538x724.png`; reproduce the complete white vertical lockup, centered near the top, with the flying emblem above `WULING` and no slogan. The supplied option-B form reference is tightly cropped, so never reproduce its clipped canvas edges; the final Logo itself must be complete. Keep the background beneath either option clean and dark enough for the white mark.
   - Prefer several complementary official views when available so the generated angle can remain faithful to the model.
   - Explicitly lock the visible front/rear plate area and vehicle nameplates. If the official campaign vehicle carries a model-name display plate, require that complete plate and exact model text; if the official reference or user calls for a blank plate, require a clean intentional blank plate. Never omit the plate mounting area, merge it into the grille, generate a black blur, fabricate registration characters, or alter a front, rear, fender, C-pillar, or trim badge.
   - Pass every approved text string verbatim, including punctuation, numbers, units, capitalization, and intended line breaks. Tell ImageGen to render only those strings and not translate, rewrite, abbreviate, or invent copy.
   - A required machine-readable QR code is the sole default exception: place the original QR asset afterward and verify it scans. Do not ask ImageGen to recreate QR modules.
11. Produce a complete ImageGen master that already includes the approved text, official Logo, verified price block when required, vehicle/product, background, CTA, and disclaimer. Deliver the user a complete image rather than loose layers or a background-only result.
   - Compare every generated character and the complete Logo construction against the locked inputs at full resolution. If either is wrong, use another ImageGen generation or targeted ImageGen edit while preserving the already-correct scene and vehicle; do not silently repair the Logo or typography with external post-composition.
12. Check vehicle identity, official-source accuracy, brand accuracy, image realism, text fidelity, price terminology, platform safe areas, and visible defects. Compare the integrated render against official references before adapting sizes. Inspect every visible display plate/license-plate area and vehicle nameplate at `100%` and at least `200%` zoom; missing plates, malformed brackets, black smears, pseudo-characters, wrong model names, invented badges, or incorrect badge placement are mandatory rework for both Volkswagen Anhui and Wuling.
13. Generate or adapt a separate complete ImageGen composition for every requested platform and placement, keeping vehicle, environment, Logo, and text together in each result. Do not stretch the vehicle, product, people, Logo, or typography, and do not treat one crop as universally valid.
14. Export the requested files, inspect the final-resolution outputs, and deliver a manifest containing platform, placement, dimensions, format, filename, specification source, official vehicle-source URLs, access date, generation approach, and status.

## Production boundaries

- Treat user-supplied copy as required and locked. Preserve its wording, punctuation, numbers, units, line-item relationships, and disclaimer hierarchy unless the user explicitly requests copy changes.
- Ask missing production inputs one at a time in the guided intake order. Each reply should contain only the next question plus any necessary choices for that question. Do not say “还需要补充以下几项” followed by a list, unless the user explicitly asks for a full checklist.
- If the user has not specified publishing platforms, ask only which platform the image will be published on, such as Xiaohongshu, Weibo, Douyin, WeChat Official Accounts, automaker APP, or another platform. After the platform is named, ask the exact placement in the next turn when multiple placements are possible, such as portrait/square/landscape cover, article image, feed image, carousel, live-room cover, topic background, splash screen, homepage banner, or mall card.
- If the user has not specified the vehicle model, ask before research or image production. Request the exact model and, when identity could differ, the year/generation, trim, exterior color, and target market. An explicit “本次不出现车型/做品牌通用视觉” answer satisfies the gate; silence does not. Never choose the most recent, most popular, previously used, or reference-image vehicle on the user's behalf.
- If the user has not supplied final displayed copy, ask for the exact headline first. After the headline is known, ask for the next required text element only if the job needs it, such as subtitle, CTA, price or benefit line, or disclaimer. Do not generate a draft image while waiting.
- If a Wuling request has no confirmed preset or custom visual style, ask for the style even when the platform, placement, copy, vehicle, scene, and colors are otherwise complete. Do not generate a draft while waiting.
- If a Wuling request has no confirmed Logo option A or B, ask for the Logo form even when all other inputs are complete. The earlier option A is no longer an automatic default. Ask the Logo question and style question in separate turns unless the user asks for a full intake form. Do not generate a draft while waiting.
- For DSSO, absence of a Logo instruction is not a blocker: apply the approved top-right VW roundel + horizontal moving-frame default. Override it only for an explicit user request or a mandatory official platform, co-brand, or campaign lockup.
- Retrieve specified-vehicle references and official Logo assets from the official brand website. Ask the user only when the official source is unavailable, ambiguous, protected from access, or insufficient to identify the exact version.
- Search current official price information when the user wants a price shown but has not supplied one. Preserve the official term exactly, such as “建议零售价”“官方指导价”“限时售价” or “综合权益”. Never turn one category into another.
- For a newly generated complete graphic, generate the vehicle, environment, exact Chinese copy, official Logo, verified price, CTA, and disclaimer together with ImageGen. Do not default to adding Logo or text afterward with deterministic layout tools. The original QR code may be added afterward because it must remain machine-readable.
- Do not use “AI background + pasted vehicle cutout” as a fallback after an integrated generation misses the vehicle. Retry the integrated render with clearer official references and stricter identity constraints. After two materially revised attempts still fail identity or realism checks, stop and request better official references or escalate to a designer instead of delivering a visibly composited result.
- Treat misspelled copy, altered numbers, invented words, malformed Logo geometry, wrong Logo color, or an incorrect lockup as generation failures. Retry with clearer Logo references, shorter locked text blocks, explicit line breaks, or a targeted ImageGen edit. After two materially revised attempts still fail, stop and request a better Logo reference or escalate to a designer; do not convert the failed result into a post-typeset or pasted-Logo version unless the user explicitly changes the requested method.
- Treat an absent required plate, malformed plate geometry, unreadable pseudo-text on a model display plate, a fabricated registration number, or an incorrect/missing vehicle model badge as a vehicle-identity failure. Retry the integrated render or use a targeted ImageGen edit on the plate/badge region while preserving the already-correct vehicle and scene. After two materially revised attempts still fail, stop and request a clearer official close-up or escalate to a designer; never approve the image because the error is small in the full poster.
- For Wuling, validate the selected lockup exactly. Option A must contain the flying emblem, `WULING`, and “人民的品质出行” in the approved horizontal/slogan relationship. Option B must contain the flying emblem above `WULING`, contain no slogan, and use the approved top-center relationship. Missing, invented, rearranged, cropped, or illegible elements fail QA. Do not add a blue block or any other invented carrier behind either option; reserve a clean, sufficiently dark image area.
- Preserve source files. Write outputs to a separate job directory and never overwrite the only copy of an input.
- Use a specialist or designer for flagship key visuals, novel visual systems, complex compositing, high-end retouching, regulated claim layouts, or work that fails repeated vehicle-identity checks.

## Supported operations

### Edit existing images

- Remove or replace a background.
- Clean unwanted objects, reflections, dirt, clutter, or image artifacts.
- Extend a background to a new aspect ratio.
- Adjust lighting, contrast, color, sharpness, and tonal consistency.
- Replace a scene while preserving the approved vehicle or product.
- Create transparent-background vehicle or product cutouts.

### Generate complete images

- Research and obtain official vehicle identity references before generation.
- Generate the specified vehicle, campaign environment, official Logo, locked copy, verified price when required, CTA, and disclaimer together in one visually integrated ImageGen render, using official vehicle and Logo images as identity references.
- Allow the generated vehicle angle and perspective to adapt to the road, terrain, camera, light, and environment; require natural contact, reflections, scale, and occlusion.
- Require exact text and Logo fidelity inside the ImageGen result. Use deterministic composition only for an original scannable QR code or when the user explicitly requests a template/compositing workflow.
- Produce two or three meaningfully different directions when visual exploration is requested.

### Compose operational materials

- Place official vehicle/product imagery, official Logo, locked copy, verified price terminology, CTA, disclaimer, and QR code into a supplied or approved template.
- Build banners, posters, covers, carousel images, long-image modules, knowledge diagrams, and marketplace cards.
- Keep editable text and layout layers when the production tool supports them.

### Adapt across platforms

- Use the approved master as a visual reference, then let ImageGen create a complete composition for each ratio with the vehicle, environment, Logo, and locked text together.
- Protect the vehicle, headline, offer, CTA, logo, disclaimer, and QR safe areas.
- Validate actual platform templates supplied by the user. When none are supplied, verify current official platform specifications before rendering. For an internal automaker APP, request its design template or exact pixel dimensions because public social-platform presets do not apply.

## Approval gates

- **Gate 1 — Guided intake ready:** publishing platforms and placements are known, dimensions are verified, final displayed copy is present, the exact vehicle model is confirmed or the user has explicitly approved a no-vehicle visual, official vehicle, Logo, and price sources have been resolved when applicable, and every Wuling task has both a confirmed preset/custom visual style and a confirmed Logo option A/B. Reach this gate through one-question-at-a-time intake, not a bundled checklist, unless the user explicitly requests the checklist.
- **Gate 2 — Master preview:** direction, vehicle, scene, color, layout, and copy placement are approved.
- **Gate 3 — Platform family:** all ratios preserve hierarchy and identity.
- **Gate 4 — Final QA:** full-resolution exports pass technical and visual checks.

For simple one-image edits, combine the gates and complete the task directly. For a multi-platform campaign family, pause at Gate 2 only when the user requests an approval gate or when choosing the wrong direction would cause substantial rework.

## Delivery

Return:

1. Complete final images with vehicle/product, background, approved text, official Logo, verified price when requested, and required functional elements already included.
2. Editable source files when requested and supported.
3. An output manifest listing filename, platform, placement, dimensions, format, platform-specification source, official vehicle-source URLs, access date, and status.
4. A concise note naming any unresolved issue, substituted non-critical asset, or item requiring human review.

Do not deliver copy strategy, headline variants, social captions, or platform posting text unless separately requested outside this skill.
