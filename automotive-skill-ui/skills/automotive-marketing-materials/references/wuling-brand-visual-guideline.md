# 五菱品牌视觉识别规范 2.0 执行规则

## 来源与适用范围

所有五菱视觉必须读取本文件。正式来源为：

`assets/brand-guidelines/wuling/五菱品牌视觉识别规范2.0版.pdf`

- 规范名称：五菱品牌视觉识别规范 / WULING Brand Identity Guideline
- 版本：2.0
- 全册：136 个 PDF 页面
- 覆盖：品牌、标志、版式、标准色、字体、影像、品牌应用与终端标志

先确认本次车型或内容属于主品牌、银标系、光标系还是红标系；不同体系的主色和影像调性不同。子品牌、车型标或联合标志必须使用对应官方资产，不能凭本规范截图重建。

除下述“用户指定宣传 Logo 二选一”外，本 2.0 版是所有五菱 Logo 规则的最高优先级依据，包括标志选择、结构、颜色、背景版本、位置、尺寸、安全空间、组合关系及禁止项。用户已批准 A、B 两种白色宣传 Logo 形式及各自版式关系；每次五菱作图必须先确认本次使用 A 或 B，不设自动默认项。用户后续提出的具体要求优先级更高。银标系仍须读取 `wuling-silver-visual-guideline.md` 处理所选方案未覆盖的事项。使用 IP 角色小五（英文名 `Wula`）、小菱（英文名 `Ling`）或其图形时，另外读取 `wuling-character-guideline.md`；中文对外内容统一称“小五”“小菱”。

## 用户指定宣传 Logo 二选一

### 选择门槛

- 在每次新生成、重大改版或跨平台重构五菱图片前，确认以下选项之一：
  - **A 左上横排口号组合标**：飞翔标与 `WULING` 横向组合，下方含“人民的品质出行”。
  - **B 顶部居中上下组合标**：飞翔标在上、`WULING` 在下，不含口号。
- 若用户没有指定，必须询问：

  > 请选择本次五菱素材的 Logo 形式：A 左上横排口号组合标（飞翔标＋WULING＋“人民的品质出行”），还是 B 顶部居中上下组合标（飞翔标在上、WULING 在下，不含口号）？

- 未确认 A/B 前停止 ImageGen，不代表用户选择，不沿用上一个任务的选项，也不因车型、风格、平台或背景颜色自动推断。
- 若平台模板、官方联名规范或活动资产强制另一种锁定关系，先向用户说明冲突并以该强制规则为准。

### A：左上横排口号组合标

#### 固定资产

- Logo：`assets/brand-guidelines/wuling/wuling-default-white-logo-lockup.png`
- 场景参考：`assets/brand-guidelines/wuling/examples/wuling-logo-placement-reference-1080x1440.png`
- 该 Logo 是 `1000 × 246 px` 的透明底白色组合标，完整包含飞翔标、`WULING` 英文标准字和“人民的品质出行”。必须整图使用，不得拆分、重排、重打标准字、改色、裁边、描边、加阴影或替换其中任何部分。
- 新生成五菱视觉时，将该 PNG 作为 ImageGen 的严格 Logo 身份参考，与车型、环境和定稿文字一并生成；逐项检查三个组成部分是否完整、清晰且比例一致。除非用户明确改用模板合成流程，不把它作为后贴图层。

#### 位置与比例

图二参考画布为 `1080 × 1440 px`。白色组合标的可见边界约为 `x=54–284 px`、`y=50–105 px`，由此得到默认执行值：

- 竖版与方形画布：Logo 可见宽度为画布宽度的 `21.4%`，左边距为画布宽度的 `5%`，上边距为画布高度的 `3.5%`，高度按原始 `1000:246` 比例自动计算。
- 横版画布：以画布短边为基准，Logo 可见宽度为短边的 `21.4%`；左边距为短边的 `5%`，上边距为短边的 `3.5%`。如平台安全区要求更大的边距，只向内移动，不改变左上角锚点逻辑和 Logo 比例。
- 所有画幅都保持左上角放置、完整比例和清晰留白。先为 Logo 预留干净的中深色背景区域，再安排标题和其他信息；不得为解决对比度问题临时增加蓝色方块、渐变底板、描边或阴影。
- 平台模板、刘海区、头像遮挡或裁切安全区与上述比例冲突时，优先保证不被遮挡，并做最小幅度内移；未经用户要求不改到其他角落。
- 选择 A 后，用户只改变文案、车型、场景或颜色方向，不视为切换到 B。只有用户明确改选 Logo 类型、颜色、尺寸或位置，或者强制媒介规范另有要求时才覆盖 A 的规则。

### B：顶部居中上下组合标

#### 形式与参考

- 形式参考：`assets/brand-guidelines/wuling/wuling-logo-option-b-user-form-reference.png`
- 场景参考：`assets/brand-guidelines/wuling/examples/wuling-logo-option-b-placement-reference-538x724.png`
- 固定结构为白色飞翔标在上、白色 `WULING` 英文标准字在下，整体上下居中对齐；不含“人民的品质出行”，不得擅自加入中文口号、横向重排或拆成两个无关联标识。
- 用户提供的形式参考为 `1000 × 684 px` 透明 PNG，但其画布四周与英文标准字底部存在紧贴或裁切。它只能用于确认结构、颜色和上下关系，不得把裁切边缘复制进成品。ImageGen 同时读取场景参考及《五菱品牌视觉识别规范 2.0 版》，最终必须生成完整、未裁断的飞翔标与 `WULING` 标准字。
- 场景参考中的辣条品牌、联名人物、车型涂装、文案、颜色、星空与沙漠只说明 Logo 的位置及视觉量级，不得作为当前活动信息或强制风格复制。

#### 位置与比例

场景参考画布为 `538 × 724 px`。Logo 可见边界约为 `x=217–318 px`、`y=91–160 px`，即宽度约为画布宽度 `19%`，水平居中，顶部留白约为画布高度 `12.5%`：

- 竖版与方形画布：Logo 组合可见宽度以画布宽度的 `19%` 为起点，水平居中，顶部边距以画布高度的 `12.5%` 为起点；高度按官方完整上下组合比例自动计算。
- 横版画布：保持顶部居中锚点，以画布短边的 `19%` 作为组合标可见宽度起点；顶部边距以画布短边的 `12.5%` 为起点。若该尺寸影响识别，可在不压过标题层级的前提下按官方最小尺寸放大。
- 平台安全区、顶部 UI、头像或裁切风险与上述位置冲突时，只做必要的向内移动；仍须保持顶部居中，不擅自移到左上角。
- 在 Logo 周围保留干净的深色或中深色负空间。不得添加蓝色方块、渐变底板、圆角容器、描边、投影或发光来补偿对比度。
- 选择 B 后，标题从 Logo 下方开始组织；不得穿入飞翔标与 `WULING` 之间的锁定空间。

## 标志与品牌符号

### 资产选择

- 本 Skill 的日常传播必须使用用户本次确认的 A 或 B。仅在用户明确要求或媒介专项规则强制时，才切换为单独的“飞翔标”或其他官方锁定关系。
- `WULING` 英文标准字和“中国五菱”标准字是独立品牌符号，结构、比例和字距不可改变。
- `WULING` 英文标准字最小高度为 `4.5 mm`，推荐置于画面底部。
- “中国五菱”标准字最小高度为 `7 mm`，作为辅助图形使用。
- 规范列出的印刷最小尺寸包括：Ling OS `10 mm`、LING Club `10 mm`、LING HOUSE `7.5 mm`。
- 只从官方品牌资产库或用户提供文件取得标志，并将其作为 ImageGen 身份参考；不得从 PDF 或成品 JPG 抠取，不得让模型脱离官方参考自由重绘，也不得用普通字体替代标准字。

### 背景版本

A/B 白色组合标使用时不得改色：通过构图让相应的左上角或顶部居中区域保持干净的中深色背景，以确保白色标志清晰。以下明度切换规则只适用于用户明确要求单独飞翔标或目标媒介强制切换其他官方版本的场景：

规范第 23 页使用一条特殊的“底图色彩明度”刻度，其中 `0%` 画成白色、`100%` 画成黑色。必须按该规范刻度执行，不能直接套用常见相对亮度百分比：

- 规范刻度 `<20%`：使用菱空蓝飞翔标。
- 规范刻度 `>=20%`：使用白色飞翔标。
- 无论阈值如何，最终必须保证标志清晰可识别；复杂照片背景先选择干净区域或建立合规承载区。

### 禁止事项

- 不得更改标志标准色。
- 不得自行把飞翔标与 `WULING` 绑定成第三种锁定关系。A 的横向口号组合与 B 的上下无口号组合是两个独立批准方案，不得互相拆件、混搭、改距或创造中间版本。
- 不得拉伸、压扁、旋转或改变标志角度。
- 不得添加阴影、立体、发光、渐变、描边等效果；规范指定的广告尾板动画、材质或终端 LED 场景除外。
- 不得把主辅助图形或副辅助纹样当作主标志替代品。
- 节日或特殊事件的标志演绎必须由品牌方发起或明确批准，不能自行创作。
- 不得为了提高对比度自创蓝色方块、色块底板、圆角图标或其他 Logo 承载容器。A/B 白色组合标应通过构图预留干净的中深色区域；只有在用户明确要求其他标志版本或媒介规则强制时，才按本规范的背景明度规则切换菱空蓝或白色飞翔标。官方规范明确提供的完整承载版式只能原样使用。

## 版式与安全距离

本节表格适用于没有采用用户指定 A/B 组合标，或目标媒介明确强制官方专项版式的情况。日常传播按用户选择分别执行 A 的左上角规则或 B 的顶部居中规则。

规范用 `X` 表示画面短边或高度，用 `a` 表示飞翔标宽度。按目标画幅重建，不从示例目测缩放：

| 画幅 | 标志尺寸 | 外边距 |
|---|---|---|
| `1:1` | 标志高 `1/15X` | 上下左右 `1/2a` |
| `2:1` | 标志高 `1/15X` | 上、左、右 `1/2a` |
| `3:1` | 标志高 `1/10X` | 上下左右 `1/2a` |
| `4:1` | 标志高 `1/5X` | 左 `a`，右 `1/2a`，上下居中 |
| `5:1` | 标志高 `1/4X` | 左右各为长边 `a` 的 `1/12`，上下居中 |
| 竖版 | 标志宽 `1/8X = a` | 上下左右 `1/2a`；使用规范标注的优先版式 |

- `4:1` 与 `5:1` 示例中的蓝色区域不得放置重要画面信息。
- 浅色底图使用菱空蓝标志。
- 横版主品牌与子品牌/车型联合应用：主品牌标志高为画面高度 `1/15`。
- 竖版主品牌与子品牌/车型联合应用：主品牌标志宽为短边 `1/8`。
- 子品牌地位低于主品牌；组合示例要求相关标志视觉高度一致，具体位置可按画面调整。
- APP 头像、网页、经销商广告和户外物料有专项比例，遇到这些版位必须回看原 PDF 对应章节，不能用普通海报规则代替。

## 影像调性

### 主品牌

- 简约、干净、大气，优先使用自然天空背景，表达积极向上与“飞翔”感。
- 有人物时使用有温度、朝气的中国面孔，可为驾乘者或具有民族自信感的年轻人。
- 保留真实生活感和主体负空间，避免堆砌装饰或刻意摆拍。

### 银标系

- 强调产品高级感、精工感、造型和材质清晰度。
- 人物呈现有品味的现代生活，格调更高但不做作。
- 具体银标 Logo、色彩、字体、影像、版式和辅助图形按 `wuling-silver-visual-guideline.md` 执行。

### 光标系

- 强调新能源、轻生活、年轻、时尚、潮流与现代感。
- 人物和构图可更有张力与趣味，但保持车型真实。

### 红标系

- 强调真实、务实、可靠和新时代奋斗者。
- 人物处于自然生产或生活状态，动作不刻意，不使用浮夸的豪华叙事。

## 字体与排版

- 中文专用字体：方正兰亭黑系列。
- 英文与数字专用字体：Avenir 系列；规范明确要求英文和数字必须使用 Avenir。
- 主标题/副标题：方正兰亭中黑简体 + Avenir LT Pro 65 Medium。
- 正文标题：方正兰亭大黑简体 + Avenir LT Pro 85 Heavy。
- 正文：方正兰亭纤黑简体 + Avenir LT Pro 35 Light。
- 正文强调：方正兰亭黑简体 + Avenir LT Pro 55 Roman。
- 大多数场景采用左对齐。
- 中文语境使用中文标点，英文语境使用英文标点；数字与拉丁字母均使用英文字体。
- 中文字号超过 `40 pt` 时，英文字号比中文字号大 `5%`。
- 特殊中文标题可按批准场景使用造字工房明黑或斗鱼追光体，不能作为常规默认字体。
- 当前 Skill 未绑定五菱字体文件。正式生产前检查本机是否有合法授权字体；缺失时向用户索取字体包或批准的回退方案，不得静默替换后正式交付。

## 辅助图形

- 主辅助图形由飞翔标演变，可做品牌画面造型，但要使用批准的构造或官方资产。
- 副辅助连续纹样的高度固定为 `12` 排菱形，不得增减；左右数量可随场景变化。
- 副辅助纹样左右和下方按单个菱形 `1/2` 位置裁切，并以画面中心向两边延续。
- 规范展示的主辅助图形多样化案例不是任意发挥授权；不确定时使用官方提供版本。

## 输出前质检

- [ ] 已确认主品牌、银标系、光标系或红标系，没有混用体系。
- [ ] 本次 Logo 选项 A/B 已由用户确认，不是 AI 默认或沿用上次任务。
- [ ] 选择 A 时，完整白色组合标按左上角 `5% / 3.5% / 21.4%` 规则放置，飞翔标、`WULING` 和“人民的品质出行”均完整清晰。
- [ ] 选择 B 时，完整白色上下组合标按顶部居中规则放置，飞翔标在上、`WULING` 在下，不含口号，且没有复制形式参考中的裁切边缘。
- [ ] 飞翔标、标准字、子品牌标和车型标来自官方文件。
- [ ] 标志颜色、背景版本、比例、外边距及画幅规则正确。
- [ ] 没有产生 A/B 之外的新组合、拉伸、旋转、描边或添加效果。
- [ ] 数字端使用准确 RGB/HEX，印刷端使用对应 CMYK/Pantone。
- [ ] 摄影调性符合对应品牌/车系，人物与车型身份真实。
- [ ] 中文、英文和数字字体符合规范；缺少授权字体时未静默替换。
- [ ] 历史示例中的车型、文案、价格与权益未被当作当前事实。
- [ ] 最终成品逐字、逐图、逐尺寸检查并通过 `automotive-visual-qa.md`。
